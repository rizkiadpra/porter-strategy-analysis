# porter-strategy-analysis

Claude Skill untuk menganalisis, menguji, dan merancang strategi kompetitif memakai kerangka
Michael Porter sebagaimana dijabarkan Joan Magretta di *Understanding Michael Porter*.

Isinya dua alat yang sengaja dipisah levelnya:

- **Five Forces** — level industri: seberapa menarik struktur pasarnya, force mana yang paling menentukan profitabilitas.
- **Five Tests of Strategy** — level unit bisnis/inisiatif: value proposition → value chain & biaya relatif → trade-off → fit → continuity.

Plus Langkah 0 (audit pola sebelum mendefinisikan value proposition) dan daftar red flag per tahap
— "terbaik/terlengkap" tanpa pilihan nyata, operational effectiveness yang disamarkan jadi strategi,
mission creep, straddling, pivot yang dipicu tren.

Bahasa instruksi: Indonesia.
